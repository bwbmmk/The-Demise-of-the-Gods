# 神之殇 · 厄里昂：万家微火

版本 0.15.1。初步完成序章、五幕与三个结局；北岸保留图文幕间。

双击 `神之殇-demo.html` 离线游玩，或 `npm start` 后打开 http://127.0.0.1:4173/?v=0.15.1。

## 操作与入口

- 跳跃 / 二段跳：空格、W 或 ↑；滑铲：S 或 ↓；A / ← 刹步。
- 第三幕 E 长按照忆；第四幕楔前 A / ← 后撤，Shift / → 消耗余烬冲刺；最终战 A/D 或左右键走位，E 按住接忆，松开发还。
- Boss 战通道独立提供四场练习。执炬王直接进入三楔战，第三楔断即结算。
- 剧情纯享版复用主线实际正文。创作者入口使用用户约定的简单密码，本地修改同步主线；创作者模式禁用游戏快捷键。

## 当前王座战与终幕

第四幕改为诱锤断楔：黄印跟随，红印锁定后后撤，让王的攻击砸断黎明楔。三段加入震波、滑刃、高浪与踏击组合。三楔全断解安眠锁，王存活，门未开。

最终战三阶段、九次反击，每掉一格血都加快出招，末段连招增至六招。完整战斗有十三种招式与组合：双向夹击、连续追枪、横扫地火、全场高位王令、火牢、落火与低刃齐射、陨日等；必须把走位、跳跃、二段跳与滑铲组合使用。落体本身有空中判定。好结局扩为八页，加入生成插画、终战背景、18 秒插画运镜短片与分阶段原创配乐。角色生成配音及模型视频尚未完成。

## 开发与验证

`npm test` 运行单测；`npm run build` 生成离线 HTML；`node tools/verify-chapter.mjs` 验证打包页面流程。只改源码，勿直接改生成 HTML。

188 项 Node 测试与 591 项打包页面检查通过。本版新增预警无伤、错误动作受伤、二段跳必要性、错过反击恢复、确定性与实体可见性回归。自动回放不代替真人盲玩或实机移动性能测试。
