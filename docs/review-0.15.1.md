# 0.15.1 终战强度验收（含剧透）

用户要求终幕强度高于第四幕，并随执炬王失血提高攻击频率。本版调整第五幕的最终对决，正式流程与独立练习共用，不改变三结局。

## 已实现

- 每失一格血都缩短预警、蓄势、招间连接、受击恢复并提高弹速、落速，最后一格的预警为 0.696 秒，蓄势与恢复各 0.16 秒、连接 0.072 秒。阶段提升继续发生于三击、六击。
- 波体越过战区边缘立即清理，取消它已经离开却仍等固定寿命的空档。
- 七种新招式/组合：双向低刃、独立追踪后锁定的三连枪、按序地火、覆盖全场上方的王令、落火与低刃混合齐射、火牢限位与低刃、陨日与追刃。全流程覆盖十三种，三阶段为 3–4 / 4–5 / 5–6 招连段。
- 延迟实体保留自己的预警；后续追枪先追踪再锁定。王令覆盖跳跃高度但留滑铲间隙。陨日的落体身体高度与图片相符，地火使用火焰轮廓，来自身后的刃有屏幕边缘箭头。
- 漏接记忆后换组继续，不复制同一轮；所有提示仍只在第一次出现时显示，方向/落印/地火顺序常驻。

## 实际验证

188 项 Node 测试通过，591 项打包页面断言通过，无 JavaScript 错误。新增覆盖逐格压力递增、同一低刃真实连续施放时间缩短、双方向碰撞、追枪锁定、王令站立/跳跃受伤与滑铲无伤、混合实体、延迟预警、离场清理。正式与练习均用真实键盘输入完成无伤。

确定性输入回放终战约 111 秒，第四幕全路线约 144 秒、独立三楔约 40 秒；每场均保留三格生命。终战单轮由三招增至六招，回放中的纯蓄势/连接/恢复空档约占 7%–13%。这说明密度与可达性，仍需玩家实战确认最终难度感受。
