# visual-kit 取舍与适配

评审版本 0.10.1 · 2026-10-05。已阅读入口、事件氛围、场景氛围和后处理实现，查看背景对照截图、三张 PNG 与模型预览；本表记录实际采用范围。原目录留存，不修改候选素材，不将演示页当作主游戏发布。

| 内容 | 当前取舍 | 原因及后续边界 |
|---|---|---|

| assets/Flat_vector_character_turnarou_2026-10-05T03-12-02.png | 留作造型参考 | 正面展开姿势不能替代跑、跳、滑铲帧；服装颜色与现有暗红披风需要统一，本版保留已验证膝关节的动作 |
| assets/Wide_cinematic_background_plat_2026-10-05T03-12-04.png | 暂不使用 | 建筑主要是中式塔阁，和现有拱桥、废城、三域粮仓不一致；图内有 AI/WORKBUDDY 标记，不能直接做成连续关卡背景 |

| src/postfx.js 与 src/index.js 整包包装 | 当前不安装 | 包装 burst/event/render/resize 会叠加当前效果；额外暗角、钟波与全屏后处理可能降低危险辨识度。用户此前要求提亮边缘，应先按效果逐项比较，再决定保留哪些 |

本版实际采用为烬的 SVG 肖像设计要素与三幕远景重绘。序章画面保留现行构图，没有导入 PNG、3D 运行库或 visual-kit 总装。BackgroundDepth 独立于 Runner，只读距离与场景名，几何按四类场景/两层缓存，滚动不累积；没有额外粒子或基于时间的漂移。新增窗灯表示当前屋里尚有人，不是结局已经完成。

已对比正式离线包十二处场景的同一帧：[第一幕](screenshots/background-compare-district.png)、[第二幕](screenshots/background-compare-covenant.png)、[第三幕](screenshots/background-compare-fate.png)。两帧关闭同一随机扬尘；桌面与 960×600 各 37 项检查通过，无 JS 错误，新增远景可见、y≥460 路面/实体像素与原版一致、模拟/地图不变、缓存有界。原生源码回归 128 项，实际打包流程 417 项；仍未在真实移动设备测帧率，不据此宣称性能提升。

后续 T-06：剩余候选效果先核对真实事件与现行剧情，再比较与钟波、护灯、锁链预警的叠加；验证暂停、重开、减少动态及画质降级，按 T-02 在目标设备测帧率和资源占用。整包仍未适配，质量调度、事件特效与实际性能改善仍待验证。
