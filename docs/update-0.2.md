# 0.2 · 余火重燃

## 新增体验

- **剧情开场**：四幅原创 SVG 分镜描绘光之契约、诸神陨落、弥娅传火、烬的旅程。上一幅、下一幅、键盘翻页和直接跳过均可用；重试直接回游戏。
- **原创配乐《葬火》**：72 BPM、D 小调、16 小节主题；实时 Web Audio 合成主旋律、和声、分解音、钟声、低鼓与短回声。章节增加配器密度，暂停时降低音量；手动静音意图在本次页面会话保留。
- **独立音频**：`assets/music/ember-requiem.wav`，约 57 秒，22.05kHz 单声道 PCM。与游戏共用乐谱，但离线与实时音色有差异；不是商业录音或真人交响乐。仅游戏内即时合成就能离线播放配乐。
- **掌心余火**：明确托火手势、三层火苗、局部光晕和逸散火星；二段跳出现环形火光，落地扩散冲击环。
- **连续动画**：奔跑摆腿、首跳蹬伸、空中收腿、二段跳光环与更强收腿、落地压缩、贴地滑铲，各有独立连续姿态。滑铲不再将站立角色整体倾倒。
- **高刷拖尾**：模拟每秒采样 120 次，最多保留 60 个姿态；渲染在物理步之间插值，掌心位置生成连续丝带，稀疏角色残像补充速度感。显示帧率仍取决于设备与浏览器，不宣称所有设备锁定 120 FPS。
- **路线变化**：连续坡道与高台共用渲染/碰撞高度曲线；两处青色风印自动腾空并保留一次空中跳；三个高处共鸣环可选收集，每个恢复一格余火。地面主路线不要求全收集。
- **小目标**：连续记忆收集形成连忆，受伤或中断 2.4 秒后清空；结算展示最长连忆与共鸣数量。
- **章间视觉差异**：圣所玫瑰窗和光束、终段巨大神骸肋骨和低强度裂隙光，保留危险轮廓可读性。

## 技术边界

依旧无第三方依赖。新增 `animation.js / music.js / story.js`，打包工具按依赖顺序一并内联。坡面由 `groundAt(x)` 定义；新增收集和风印状态纳入检查点恢复，避免回档重复刷取。

动作没有加入新的付费数值或战斗系统。风印自动触发，共鸣环可绕过；三个基础操作保持不变。长按与短按跳跃高度目前相同，优化集中于姿态、输入容错和显示插值。

## 验证

16 项自动化测试覆盖原有动作和全路线无伤通过，以及坡面贴地、坡上落地、风印次数、共鸣恢复与回档、连忆中断、滑铲视觉高度、乐谱循环、四幅分镜、WAV 非静音及幅度余量。浏览器检查覆盖序章翻页、跳过、进入游戏、声音切换和音量输入、桌面与窄屏布局。

下一步仍建议真人试玩判断风印与共鸣环的预判距离，以及音乐和音效在真实设备上的混音平衡。
