# 执炬王 · 王座仪式战（当前设计）

版本 0.14.0 · 2026-10-13。第四幕强化版、第五幕最终对决与三个结局基础流程已实现。

## 战斗循环

躲过连招 → 王收势、回路敞开 3.2 秒并补足两枚星火 → 近楔按住 E 连续反灌（也支持轻按两次） → 楔碎、仪式反冲 → 推进下一段。

第一楔三连：跳焰刃、滑炬刃、熔渣；第二楔四连：火雨、双重践踏、滑炬刃、跳焰刃；第三楔五连：熔渣、炬刃、高浪、双重践踏、炬刃。重试有另一组顺序。危险通过后衔接，不等屏外实体跑满寿命。招招独立完整预警，实体消退才续招，取消隐形重叠队列。每组必经完整攻击，提前按 E 不再绕过整场战斗。

## 本次修复依据

- 旧落体在 telegraph 分支继续进入伤害判定，且预警已消耗寿命。
- pending 在未到延时即被丢掉，重叠队列实际缺招；环的寿命条件恒真。
- 活跃攻击绘制被 aim/charge 分支包住，impact 时消失。
- 楔交互引用了屏宽参数 w 而非 wedge，产生无效坐标。
- 文案仍教引锤，音效仍用旧招式 ID，反击 HUD 同时带 hidden 类。
- 多种攻击以 airborne/slide 直接免伤，内核在恒定远离玩家的王脚下，提示无法兑现。
