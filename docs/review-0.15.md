# 0.15 验收复盘（含剧透）

## 实际改动

第四幕取消站桩灌注，改成诱导王的落锤砸断黎明楔：黄印跟随、红印锁定、后撤避锤。落锤区域里的玩家仍受伤，误引可重试。三楔保持原来的安眠锁因果，王存活、真门未开。

最终战九次反击、三阶段。玩家可左右走位，火雨与追身火枪的下落实体具有空中碰撞；新增裂地火柱，高浪需要二段跳，高位攻击需要滑铲。阶段间有两秒升势，后期速度及组合压力增加，反击仍需接忆与松开发还。

好结局扩为八页：王败后护火、过往承诺与控制、人间互助的证据、自愿交权、烬恢复自己并想活下去、尝试分火时看到身体代价、告别、献祭及后来的人间。必要剧情不依赖收藏。旧四页创作者覆盖使用稳定键对应原段落，新增页不挤占旧编辑。

加入三幅生成美术、18 秒插画运镜短片、三阶段终战音乐及结尾主题。详见 [素材与能力边界](ending-assets.md)。

- Node 测试 182 项通过，覆盖三阶段无伤、走位范围、落体空中碰撞、预警不伤人、站在锤下受伤、剧情顺序、音乐阶段和旧编辑键。
- 确定性操作回放：第四幕全路线约 144 秒，独立三楔战约 40 秒，最终战约 102 秒，均无生命损失。此为可达性证据，不代表真人难度已经合适。
- 打包页面 587 项断言全部通过，无 JavaScript 错误；验收覆盖正式流程、独立练习、检查点、暂停、结局选择、创作者共享文本、图片解码、片尾视频解码和关闭返回。报告位于 `.verify/chapter-flow-report.json`。
