## 2. 核心与表达

这是关于**谁来承担黎明**的故事。为神送葬还要回答活人如何过冬；保住秩序也必须允许人拒绝承担代价。烬从找回自己的名字出发，看到死后契约仍在伤人，知道自己当年关门后，决定亲自把门打开。最终由玩家选择延续神权、毁掉神权，或让烬自愿献出自己，把神权归还万家。第三条路终结长期依靠神和记忆税的供给，让人类自给自足。

玩法：连续动作中读懂危险，再用已学动作改变环境。叙事：每个节点说明“我们要去哪儿、为什么、做完发生了什么”，一幕结束推进一条明确因果，不用谜语代替必要解释。人物对白说具体的饭、药、船、种子和名单；抽象主旨由行动与后果表达。大标题承担画面的史诗感，正文与对白交代当下的因果；保留有画面、有节奏的凝练句，不把所有文字一律改成口语。主界面恢复“众神已死，长夜未尽……”三句，序章恢复初版四个标题和第一幅太阳构图；正文保留当前同路动机，删除旧版“还记得一个承诺”等失忆冲突。整体视角跟随烬：目标讲清，过去留疑。只写他亲见、他人当面告知、或实际读过的证据；不借旁白泄露失忆前的行为。少量感官断片、旧刻痕和未辨声音保留神秘感，发现证据后必须回收。世界档案只讲出发时已知，手记用烬的观察记录，不充当全知蓝图。

短篇规模，序章 + 五幕。后幕在前幕动作上增加改变决策的挑战，先教学、后组合验证。不通过重复空路、堆对白、单纯提速延长时长。预计完整体验 25–40 分钟，实际盲玩后再调整。

## 3. 世界因果：当前正式设定

### 记忆与现实

厄里昂本来不稳定：太阳多年不升、潮汐吞城、道路和季节改变。被记住才意味着真正存在；记忆是现实的一部分，名字是最牢固的锚。原初火把人们的记忆转成“世界仍应如此”的证明，让白昼、潮汐等法则稳定。

灰潮没有意识、目的或饥饿。它是失去“被记住”力量的现实坍塌。地方先失去名字、共同经历，再失去街道和住户。书写有助回想，不能替代真实的互相记忆；记名桥用三人的生活细节实际验证这条规则。

### 从自愿到强征

七个普通人献出名字，进入原初火，分别承担白昼、潮汐、风、丰收、安眠、道路、命运。最先是白昼孩子：只守一夜，天亮即可回来。之后每次请求都有救命理由，却一次次延长职责，最终再没人叫他回家。

人最初一生只自愿给一小段普通记忆。城市扩大，神权磨损诸神的凡人记忆，需要越来越多供给：一生一次 → 十年一次 → 每年 → 新生儿强制登记 → 死者也被征收。原契明确允许人拒绝献祭、神卸任。祭司害怕秩序崩塌，删掉两项权利；后来的人甚至不知原文存在。不能归结成一个坏人操控整个历史。

### 战争与死后回路

太阳神之心是开启无名之门的核心钥匙，同时保存成神前的最后记忆，使他仍记得回家的约定。他要终止旧约、打开无名之门、归还所有记忆、让七神死亡；六神各有对法则失控的恐惧，战争因此爆发。

神由凡人的心、掌管自然的神权、祈祷回路组成。战争杀死了有意识的人，没有彻底关闭神权和回路。死神不会听见、思考或回答，回路却按旧指令继续抽取记忆，神殿也继续征收。终止强征和保留自愿照料神权是可以区分的选择。

### 烬当年做过什么（第三幕才揭示）

烬是太阳神的守门人。门打开时，积存记忆涌回，但太阳、海堤、道路、庄稼失控。太阳命令开门，六神命令关门，濒死凡人求救。烬清楚情况，自己决定关门，又从背后刺穿太阳，阻止再次开门。他就是弑日者，没有幻觉、控制或欺骗替他免责。

战后烬无法面对自己的选择，主动烧掉本名，把大部分记忆投入太阳余火。死亡找不到无名的他，灰潮无法完整抹去，余火维持身体，因而活了千年。序章只交代失名与余火维生，不预告他弑日；全部因果在第三幕证据中回收。

原稿第八节“如果当时不开门，无数人会立即死去”与前文开门导致灾难相冲突。本蓝图解释为“如果继续开门”；原稿保留原文，后续演出必须按开门灾难—主动关门的因果编排。

## 4. 人物的选择与知识边界

- **烬：** 初衷是找回本名，千年生存来自余火。第一幕见到征收单和认不出女儿的病人，追问王重燃太阳后是否仍收记忆；未查明门后真相，不肯交心。第二幕老妇人仍被催缴，令他开始想把停征这件事做完。第三幕确认关门的是自己，放弃当次记忆余火救陌生人，之后继续前进为了完成当年留下的事。不是立刻自封救世主，也不靠万人称赞消掉当年的理由和后果。
- **弥娅：** 盲眼抄名人，调查征收簿与祈祷回路后得知开门可以归还记忆、让六神真正死亡；她从一开始就为送葬而走，烬为本名而走。两人交易后同行至第三幕。序章不知道他弑日，第二幕因剑痕开始怀疑，第三幕亲见证据后离开；不复仇、不原谅，建立每人至少被另外三人记住的避难网络。第五幕回到火旁是为了活人，不是赦免烬。
- **阿昼：** 太阳神成神前最后记忆中的孩子。最初只守一夜，保留回家的承诺。第一幕揭身份，幕间揭名字；两者不藏在可选收集中。
- **执炬王：** 最后王国粮食与燃料只够七夜。他要重造太阳，即使复活记忆税。威胁真实，论点必须被现实互助回应；不改成只想统治的昏君。
- **韩蕙、常晚、岑渡：** 医者、报时人、摆渡人；互忆稳桥，分别护灯、敲钟、送印。幕间后留在北岸，后来可以独立组织食物、修桥、运火，不只等待主角。
- **陆承：** 追索兵和病孩的父亲，见小灯救人仍相信王庭太阳。他带配给单复命，不因一碗热水就突然背叛全部信念。
- **照料者：** 第二幕有人愿意留下护堤、守种子。他们能退出，也能继续自愿支持神权；烬只断强征链，不替他人做终身决定。

## 5. 已实现叙事与玩法

### 序章

四幅开场恢复“人们献出记忆，换来白昼”“后来，太阳也死去了”“最后一缕火，交到你的手中”“为逝去的神，走完最后一程”与对应图画。正文从烬读到的祭文、失名的现状、弥娅的调查与送心换名的约定进入；神心隐痛与哭声只留下感官疑问。七人起源和原契拒绝权留到实际证据处再揭。不提前点破太阳童年或烬弑日。沿路空碑、弥娅方法、神骸回路、孩子哭声、七夜追索令提供证据；到门遗址看七处锁痕。两幅收尾交代六锁和街区救人，孩子说“别让他们再成为神”。

序章终点只是从无名之门遗址侧缝进入祭道，不能演成已经彻底打开真正的门或完成诸神葬礼。结算主按钮进入第一幕开场；重玩次要。

### 第一幕

去旧屋接韩蕙 → 钟楼接常晚 → 渡口找到岑渡；船被撞坏，只能走桥。说起包扎时铜片先恢复，桥前互述治病/等船/包扎，三段桥面依次恢复。弥娅参与读名、提出重述往事，在桥端道路锁旁等候。

神殿遗民发射灰弹，先预警后攻击；他们认为送葬亵渎。桥心军官则奉王命索心复燃太阳，明确七夜粮煤期限。韩蕙先展示记忆征收仍在伤人；战前五页里烬追问重燃后账是否停止，军官要求服从而未作答。烬要亲眼查门后的记忆，也还想找自己的名字，因而拒绝交心。并非已经知道王全错，或仅凭孩子哭声就开战。常晚敲钟破盾、岑渡送青色回火印、韩蕙护身一次。三轮依次增加低刃、高位光幕、紫色落印：跳、滑铲、二段跳。回火印命中后立即重新长盾，约 .72 秒成形；军官带盾恢复、蓄光、齐射，攻击结束再由常晚敲钟震裂。首轮盾在蓄光时生长；跳接器物后余火飞行命中，漏接重投；军官始终在前方 480px，无法绕过结算。

军官退开，三人过桥；道路锁在终点有实体画面，幕末明确解锁。随后回看只承诺一夜的记忆、孩子长大被戴冠，确认他就是太阳。弥娅不是第四名桥战助手；三名协助者不在第二幕地标里被复制。

### 幕间

五幅图文作为第一幕北岸尾声，与第二幕衔接。陆承女儿、配给单、床边小灯、轮值、阿昼姓名都有明确因果。火仍要煤和人照料，不能凭空解决全城严寒。三人与住户留下，烬与弥娅继续旅程。无寒雾跑图、十二秒携灯或三路灯挑战；旧模板保留不注册。

第一幕结算先进入幕间，读完/跳过返回原结算，再进入第二幕。正式衔接归档 b0–b5，br0 是首幅布条观察。菜单回看统一进入剧情纯享目录，可直接选北岸幕间，接着读第二幕，或返回菜单；回看不归档。不消耗生命、得分、模拟时间或检查点。

## 7. 实现与表现约束

- 修改模块源码，测试后构建离线产物；不直接修生成 HTML。原生 Canvas / SVG / WebAudio，无联网资源依赖。
- 演出与模拟分离，暂停和翻页/跳过不改变数值。每个发布幕都有独立可翻页、可跳过的短开场与收尾。后续已可玩时主按钮前进、重玩次要。
- 必要记录沿途或幕末取得，可选共鸣只补人物。手记只显示已解锁内容，旧条目稳定 ID 保留、正文按新版重写；新增 a15 仅第一幕正式幕末解锁。完整蓝图和原稿链接标明剧透。
- 人体膝关节方向不反折；支撑脚后推、摆动脚抬起前进，抬髋避免蹲跑；碰撞与姿态分离。每次路线调整必须验证无伤可达。
- 三域都有实际决策；第二幕丰收背景是粮仓、种子袋、育苗盒、温热铜管，原安眠病房撤出当前路线。内部 c-sleep / dream-* 是存档或机关稳定 ID，不是玩家看到的领域名。
- 弥娅用蒙眼布、手杖、铜片区分；在分镜、对白、安全落脚地标及道路锁旁出现。尚无独立随行动作 AI、身体碰撞或护送玩法，不把视觉同行写成已实现第四名战斗助手。
- 桥战紫色落印用旋转符印、地面刻环与三簇地火，仍按原 1.05 秒预警、72×160px 危险区判定，二段跳规则不变。护身消耗即断开韩蕙连线，光罩碎片短暂散开；岑渡只在送印时拉长绳，闲置绳不冒充护身连接。
- 配色冷灰绿/旧金/暗红，暖光小面积，危险轮廓优先；保持提亮遮罩、精简 HUD 和按钮反馈。锁进度在正式三幕显示，沿当前路线计数。
- 《葬火》跑酷主旋律与事件音乐保持听感衔接，减少动态设置沿用；暂未新增配音或外部美术资产。
- visual-kit 采用角色设计要素和背景对照中的远景层次：烬为原生 SVG 肖像，三幕十二处场景新增两层远景屋脊/海岸/断墙，少量灯光嵌在实际屋窗内。背景止于逻辑高度 y=450，保持照忆落脚台、路面和攻击预警优先；第二幕风海场景稀疏，第三幕遗迹没有人物剪影或提前分权的灯火。序章构图沿用原版。带塔阁的 PNG、31MB 模型、贴地光点、缺口剪影和整包后处理不采用。详见[素材与特效评审](visual-kit-review.md)。本版没有新增联网或大体积资产依赖。

## 8. 验收与下一步

当前 188 项 Node 测试、591 项实际打包页面检查通过，无 JavaScript 错误；正式五幕、全部检查点和四场独立 Boss 练习均有无伤可达路线。22 处对白暂停、翻页和手记返回保持模拟；照忆落脚时暂停保留支撑与光，注火与灰潮也冻结；第四幕对白暂停不推进王的相位与追兵距离。首个避难点只有真实 E 输入完成才消耗余火，不因跳过对白或已读手记提前救人。常亮撞墙、常暗掉落、灰潮追上回档、黎明楔挡停不掉血不回档、追兵命中只扣一格余火不回档、救援状态重置、命运锁与安眠锁必经归档均有测试；预警不伤人、单跳不能躲高浪、悬空刃不能跳过、误引落锤可重试及实体绘制均有覆盖。检查点落在障碍或断桥内会被 `validateLevel` 直接拦下（复活即受击/坠落）。纯享版新增密码门和本地创作者文本覆盖，修改会同步手记、主线对白和共享分镜；覆盖不写入正式玩家进度。终幕权柄交付与三个结局已经在第五幕及独立纯享目录呈现；前四幕不提前揭示。
