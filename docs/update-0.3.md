# 0.3 · 记忆之火

本版以“角色有生命、场所有身份、前进有发现”为核心。

- 三境：灰绿旧城、深蓝封闭圣所、冷灰神骨深渊；地表/粒子不同，火祭碑之后渐变转场。
- 三格余火对应充盈、减弱、微弱；补火与受击平滑过渡。连续丝带沿掌心运动，保留少量淡残影。
- 出场 2.8 秒、战败 2.1 秒、入门 4.2 秒；可暂停、跳过，不计入跑酷耗时。
- 9 条必要主线记录 + 3 条可选共鸣记忆；J 打开手记，本地保留已读，未知内容不提前展示。
- 序章出口修订为第一道门槛，孩子请求放在终点；后续五幕和真正无名之门维持完整因果。
- 25 项测试通过，包括无伤路线、叙事存储、演出终态和实际渲染分支。浏览器校验与边界见 [技术架构](architecture.md)。
